🔦 SpotLight Test Page

Each button triggers a specific classification category. Open the SpotLight popup to see requests appear in real time.

Known Tracker Requests Tier 1

Sends requests to known tracker domains. These should be auto-blocked by DeclarativeNetRequest and appear as "Auto-blocked" in the popup.

Canvas Fingerprinting Tier 2 — Fingerprint

Draws to a canvas and extracts a data URL, then sends it to a mock endpoint. When spoofing is active, the canvas data should be subtly different.

Geolocation Request Tier 2 — Location

Requests geolocation and sends coordinates to a mock endpoint. When spoofing is active, coordinates should be (0.0, 0.0) — "Null Island".

Extension Probe Tier 2 — Ext. Probe

Attempts to detect installed browser extensions by probing for known extension resource URLs.

PII Leakage Tier 2 — PII

Sends a POST request containing an email, phone number, and name to a mock analytics endpoint.

Normal Request Neutral

Sends a standard GET request to a benign endpoint. Should appear as "neutral" with no flags.
